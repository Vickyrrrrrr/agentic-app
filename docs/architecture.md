# AgentIC architecture

Local-first, Linux-first, single-user. The OS user is the identity;
filesystem permissions are the security model. No auth, no license
server, no billing, no cloud.

## Process model

Two processes, one protocol:

- **UI shell (Electron).** Windows, menus, updater, backend lifecycle.
  Renderer talks only to `window.api`, never to Node or the network.
- **Engine (one Python process).** Owns sessions, runs, and truth.
  Frozen binary in prod, `server/run.sh` + system Python in dev,
  automatic fallback via health-gated startup.
- **Protocol:** HTTP + SSE on loopback, per-boot token. A shell around
  a server does not make loopback private, so the token stays.

Target, not yet built: UI survives engine death mid-run and reattaches
from the ledger (startup gating exists; reattach does not).

## Package layout (`server/src/agentic_server/`)

Flat package today; import direction is one-way by review:

  api (`main.py`) -> agent, vlsi, runtime | agent -> vlsi, runtime
  vlsi -> stdlib only (+ pydantic for lint) | runtime -> vlsi

`server/main.py` is a shim (launchers depend on its path).
`vlsi/` takes no model, network, or tools — its tests run anywhere.

## State

Run events: sqlite/WAL ledger (`run_ledger.py`) with JSONL fallback.
Design state, checkpoints, sessions: files under `.agentic/` (target:
same ledger; `job_queue.recover()` is the seed for boot recovery).

## Execution

Fixed-argv tools run through `exec_service.run` (no shell, cwd jail,
timeouts, output caps). The agent `bash` tool keeps shell semantics in
`run_bash` (cwd pinned to workspace). Sidecar supervision
(`agentic_runtime` Popen) is lifecycle, not tool execution.

## Contracts and config

- `models.py` (pydantic) is the contract source;
  `docs/openapi/engine.json` is generated by
  `scripts/export_openapi.py` (TS codegen from it: pending).
- `config.py` registries every `AGENTIC_*` var; startup-critical reads
  go through it, deep reads migrate opportunistically.
- `/health` = alive. `/version` reports service/protocol/mode
  (desktop compatibility check: pending).

## Removed, deliberately

Supabase/Lemon Squeezy/license/entitlements/billing/usage-metering,
paywall + Google sign-in, auth deep-link flow, `PyJWT`, team/collab
machinery (bus, spaces, PRs, approvals, containers), WSL shims.
Kept: EDA license words (`SNPSLMD_LICENSE_FILE` — chip-tool licenses),
macOS `entitlements.plist` (sandbox config).

## Bundled backend

`scripts/freeze_backend.py` (PyInstaller one-dir, ubuntu-22.04 floor;
`siliconcompiler`/`amaranth` excluded, both degrade gracefully).
Desktop tries the binary first, falls back to `run.sh`. Release CI
freezes per platform. Previous attempt was reverted for glibc + size;
excludes + one-dir + fallback answer that.
